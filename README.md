# Tulipshare

Tulipshare is a London-based impact investor and shareholder advocacy group that uses activist investing — shareholder proposals, board and ESG-team engagement, and other shareholder rights — to push for ethical and sustainable change at the world's largest companies, working with foundations, asset managers, universities, and pension funds.
